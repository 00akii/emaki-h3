# 01. 準備 — 依存を入れて起動し、「設定」画面で確かめる

前提となるソフト（ComfyUI 0.33 以降・Python 3.10 以降・ffmpeg・任意で LM Studio / Eagle）と ComfyUI 側のノードは [README の「必要なもの」](../README.md#必要なもの) を見てください。この章は「それらが入ったあと、アプリが動くまで」の手順です。

## 1. 依存パッケージを入れる

アプリのフォルダで:

```bash
pip install -r requirements.txt
```

**ComfyUI のポータブル版（`ComfyUI_windows_portable`）を使っている場合は、システムの Python ではなくその中の Python に入れてください**（ポータブル版の Python は PATH に無いことが多いため）:

```bash
..\python_embeded\python.exe -m pip install -r requirements.txt
```

`python-multipart` も同時に入ります。これは任意の依存で、参照素材をエクスプローラーから**ドラッグ＆ドロップ**で取り込む機能（[05. 参照素材と切り抜き](05_参照素材と切り抜き.md)）にだけ使われます。無くてもアプリは起動し、ドロップ以外の機能はそのまま使えます。

## 2. config.json を作る

アプリのフォルダにある `config.example.json` をコピーして `config.json` を作り、自分の環境に合わせて書き換えます。**コードにパスは書かれていません。環境依存はすべてこのファイルです。**

最初に直すのは次の5つだけで動きます（他のキーは既定値のままで可）:

| キー | 何に直すか |
|---|---|
| `comfy_url` | ComfyUI のアドレス。既定 `http://127.0.0.1:8189`。ポートが違うなら合わせる |
| `comfy_input_dir` | ComfyUI の `input` フォルダ。**参照画像はここから読みます** |
| `comfy_output_dir` | ComfyUI の `output` フォルダ。生成された動画はここに出ます |
| `prompt_txt` / `archive_dir` | プロンプトの書き出し先。好きな場所でよい |
| `raw_dir` | 切り抜き前の元イラストを置くフォルダ（切り抜き機能を使う場合） |

`workflow_json` は既定で同梱のワークフロー（`workflows/emaki_h3_ref2va.json`）を指しています。**これは ComfyUI 公式テンプレートに、Turbo LoRA 用のサンプラー設定（euler / normal / 6step）だけを合わせたものです。ComfyUI で何かを開いて保存する作業は要りません。**

**自分で作った・保存し直した H3 のワークフローを使いたい場合だけ**、`workflow_json` をそのファイルに向けてください。その際は ComfyUI 側のサンプラーノードを次の3つに必ず合わせます。**これを直さないと、ComfyUI の既定（20ステップ）のまま動いて生成が3倍以上遅くなります**（Turbo LoRA は4〜6ステップ用のため）。

| | 値 |
|---|---|
| サンプラー | `euler` |
| スケジューラ | `normal` |
| ステップ数 | `6` |

パスの区切りは `/` で書けます（例 `"C:/ComfyUI/input"`）。

LM Studio でなくクラウド LLM（OpenAI 互換 API）を使う場合の `llm.*` の書き方、Eagle 連携の `eagle.*` は [README の「設定」](../README.md#設定) を参照してください。**API キーの値を config.json に書いてはいけません**（環境変数名だけを書きます）。

## 3. 起動する

**Windows: `start.bat` をダブルクリックします。** これが主な起動方法です。Python を自動で探し（環境変数 `EMAKI_PYTHON` → `py -3` → `python` → ComfyUI ポータブル版の `python_embeded` の順）、見つからなければ「どうすればいいか」を画面に出して止まります（ウィンドウが黙って閉じることはありません）。依存パッケージが足りない場合も、入れるコマンドをそのまま案内します。

手動で起動する、または Windows 以外の場合:

```bash
python server.py
```

ブラウザで `http://127.0.0.1:8765` を開きます。ポートを変えるときは `python server.py --port 8799`（`start.bat` 経由でも同じ引数が渡せます）。

- **LM Studio や ComfyUI が起動していなくても画面は開きます。** 足りないものは「設定」画面に赤で出ます
- 画面は `127.0.0.1` 専用です。認証が無いので、LAN や外部に公開しないでください

止めるときは、起動したウィンドウで Ctrl+C（`start.bat` ならそのウィンドウを閉じても止まります）。ウィンドウを閉じてしまった場合（Windows）:

```powershell
Get-NetTCPConnection -LocalPort 8765 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }
```

## 4. 「設定」画面で環境を確かめる

画面右上の **「設定」** を押します。上から4ブロックあり、**生成を始める前にここが緑になっているかを一度見てください。**

### 冒頭: config.json の各パス

config.json に書いたパスが実在するかの照合です。赤が出たらそのキーのパスを直し、「再チェック」を押します。

### N — ComfyUI のノード

![設定画面の N・W 欄](images/01_settings.png)

いまの ComfyUI に必要なノードが入っているかを自動で照合します。

| 表示 | 意味 | やること |
|---|---|---|
| 必須ノードが赤 | `MiniMaxH3ReferenceToVideo` などが無い | ComfyUI を 0.33 以降に更新する。**これが赤のままだと生成できません** |
| `VHS_VideoCombine` が無い | 代替あり | そのまま使えます（本体の `CreateVideo`+`SaveVideo` に自動で切り替わる。`crf`/`pix_fmt` の指定だけ効かなくなる） |
| `VHS_LoadVideo` が無い | 任意 | **参照動画が使えません。** 参照画像だけなら生成できます。使うなら ComfyUI-VideoHelperSuite を導入 |
| `SAM3_Detect` が無い | 任意 | 切り抜き画面が使えません。切り抜き済み画像を `input` に置けば生成はできます |
| `LayerUtility: PurgeVRAM V2` が無い | 任意 | 生成はできますが、**2本目以降が大きく遅くなることがあります**（[07. 困ったとき](07_困ったとき.md#生成が数分〜10分近く固まる)） |

「本体」と表示されるノードは ComfyUI 0.33 以降に最初から入っています。それ以外は ComfyUI Manager などで導入してください。

### W — 重みファイル

`workflow_json` から読んだモデルのファイル名が、その ComfyUI に実在するかの照合です。同梱のワークフローを使っている場合、重みのファイル名は公式テンプレートのものです。**開発機で使っていた重み（別名の派生版）とは名前が違うことがあります**。ここが赤のときは:

1. ComfyUI で自分の環境のモデルを選んでワークフローを保存し直す（保存し直したら、上の「2. config.json を作る」で挙げたサンプラー・スケジューラ・ステップ数の3つの値に合わせるのを忘れずに）
2. または config.json の `workflow_json` を、その環境で保存した JSON に向ける

### E — Eagle に送る

任意です。使う場合は [06. 生成と結果](06_生成と結果.md#6-eagle-に送る) を参照してください。

## 5. 上部バーの見方（起動確認）

画面上部のピルが環境の生存表示です:

- **LM Studio ·（モデル名）** — LLM の状態。ロード中のモデル名が出ます。クラウド LLM 使用時は「クラウド」表示になり、隣に「☁ クラウド使用中 · 料金がかかります」が常時出ます
- **ComfyUI · 起動中／生成中／未接続** — ComfyUI の状態。VRAM を 1GB より多く抱えていると「· NGB保持」が付きます
- **N.N / N.N GB** — GPU 全体の VRAM 使用量／総量

2つのピルの点が両方点いていれば（LM Studio を使わない構成なら ComfyUI 側だけで可）、[02. はじめての1本](02_はじめての1本.md) に進めます。

## 6. AIエージェントに任せる（上級者向け・任意）

Claude Code のようなコーディングエージェントを使っているなら、上の1〜4の手順をエージェントに指示してやらせることもできます。次の枠内をそのまま渡してください。

**この指示は「絵巻H3 自体のセットアップ」に限っています。** ComfyUI・LM Studio・Eagle 本体の導入、MiniMax-H3 の重みの入手は、ライセンスの都合であなたが別に用意する必要があります（[README の「必要なもの」](../README.md#必要なもの)）。エージェントにそこまで求めないでください。

```
あなたは今から「絵巻H3」というローカル動画生成 Web アプリのセットアップを行います。
以下の手順で進めてください。分からないこと・環境依存が強いことは、憶測で埋めずに私に聞いてください。

【前提・あなたがやってはいけないこと】
ComfyUI・LM Studio・Eagle のインストール、MiniMax-H3 の重みの取得・配置はあなたの作業に含みません。
これらはライセンス上の制約があるので私が別に用意します。あなたの作業は絵巻H3 自体のセットアップに限ります。

【手順】
1. リポジトリを確認・取得する
   - このフォルダに絵巻H3（server.py・h3studio/・static/ を含む）が無ければ
     git clone https://github.com/00akii/emaki-h3.git してください
   - python --version が 3.10 以上か、ffmpeg -version が通るかを確認し、結果を教えてください

2. 依存パッケージを入れる
   - pip install -r requirements.txt を実行してください
   - ComfyUI のポータブル版を使っていると私が伝えたら、システムの Python ではなく
     ..\python_embeded\python.exe -m pip install -r requirements.txt にしてください

3. config.json を作る
   - 既に config.json があるなら上書きしないでください。無ければ config.example.json をコピーして作ります
   - workflow_json は既定で同梱のワークフローを指しているので、私から「自分のワークフローを使う」と
     言われないかぎり触らないでください
   - comfy_input_dir / comfy_output_dir は環境依存が強いので、必ず私に確認してから書いてください。
     他は分かる範囲で埋めて構いません
     - comfy_url … ComfyUI のアドレス（既定 http://127.0.0.1:8189。動いているか確認してください）
     - comfy_input_dir / comfy_output_dir … ComfyUI の input / output フォルダの実パス
     - prompt_txt / archive_dir … プロンプトの書き出し先。無指定でよければプロジェクト内に作って構いません
     - raw_dir … 切り抜き機能を使う元イラストのフォルダ。今すぐ使わないなら空でも構いません

4. 起動して自己診断する
   - python server.py で起動する（ポート 8765 が埋まっていたら --port で変える）
   - python -m h3studio.config を実行し、出力をそのまま私に見せてください
     （パス・ノード・重みの有無が分かります）
   - http://127.0.0.1:8765 が開けるか確認してください

5. 結果を報告する
   - 赤（未設定・未検出）のまま残った項目を、理由つきで一覧にしてください
     （例: 「ComfyUI に届かない → ComfyUI が起動していないか comfy_url が違う」）
   - config.json に書いた値の一覧を見せてください（.gitignore 済みなのでコミットしないでください）
   - 実際にプロンプトを生成・動画を作る確認は、重みの用意ができてから私が画面で行うので、
     ここで止めて構いません
```

**エージェントに起動させたサーバーは、エージェントの作業が終わると一緒に止まることがあります。** 画面が開けなくなったら、自分のターミナルから `python server.py`（または `start.bat`）を実行し直してください。

エージェントの報告で緑になっていない項目があれば、[4.「設定」画面で環境を確かめる](#4-設定画面で環境を確かめる)の表と照らして直してください。全部揃ったら [02. はじめての1本](02_はじめての1本.md) へ。
