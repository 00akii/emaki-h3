# 00. はじめに

H3 Studio の操作マニュアルです。**配布先で初めてこのアプリに触る人**が、画面に沿って1本目の動画を作れるようになることを目的にしています。

## 用語（最初に5つだけ）

- **作品** — スタイル宣言・キャラ定義・参照素材・生成履歴をまとめる単位。画面上部で切り替える
- **ショット** — 作品の中の1カット。採用するたびに S01, S02, … と積み上がる
- **ブリーフ** — あなたが日本語で書く指示（場所・動き・構図など6欄）。ここからローカル LLM が英語の構造化プロンプトを書く
- **プレビュー / 本番** — 同じプロンプトを 608×352（速い・確認用）と 1344×768（遅い・納品用）で生成し分けること
- **採用** — 生成結果を作品の記録（`プロンプト.txt`・アーカイブ・ショット履歴）に確定させる操作。**採用するかはあなたが決めます。アプリは出来の良し悪しを判定しません**

## このアプリがやらないこと

- **生成結果の自動判定はしません。** 計測値と注意書きは出しますが、採用／不採用は人が決める設計です
- **MiniMax-H3 の重み・ComfyUI・LM Studio・Eagle は同梱しません**（入手とライセンスは README の「必要なもの」「公開にあたって」）
- **未検証の機能は本マニュアルに「できる」と書いていません。** 何が未検証かは [08. 付録](08_付録.md) の一覧にまとめてあります

## 本文中の数値について

生成時間・尺の上限・文字の描画可否などの数値は、**すべて開発環境（NVIDIA RTX 4090 24GB / Windows 11 / ComfyUI 0.33.1）での実測**です。環境によって変わります。出典は [08. 付録](08_付録.md) に一覧があります。
