# 07. 困ったとき

前半は**画面に出るメッセージから引く早見表**、後半は**症状から切り分ける**章です。どちらからでも引けます。

## メッセージ別の早見表

### 生成が始まらない・投入できない

| 画面のメッセージ | 意味 | やること |
|---|---|---|
| `ComfyUI に届きません（…）。起動してください` | ComfyUI が起動していないか、`config.comfy_url` が違う | ComfyUI を起動する。ポートが違うなら config.json を直す |
| `ComfyUI のキューに他のジョブがあります（実行中 N / 待機 N）` | 手動ワークフローや別のツールが ComfyUI を使用中 | その生成が終わるのを待つ。**割り込まない設計です** |
| `生成中のジョブがあります。終わるか中止してから投入してください` | このアプリの前のジョブがまだ実行中 | 進捗を確認し、終わるのを待つか「中止」 |
| `参照素材が input に無い: <ファイル名>` | 選んだ参照画像が ComfyUI の `input` フォルダから消えている | ファイルを `input` に戻すか、参照素材の選択から外す |
| 生画像についての確認ダイアログ | 背景つきの生画像を選んだまま本番生成しようとした | **本番では背景が漏れます**（実測）。切り抜いてから本番へ。プレビューならそのまま進んでよい |
| 参照動画が使えない旨の表示 | ComfyUI に `VHS_LoadVideo` が無い | ComfyUI-VideoHelperSuite を導入するか、動画を外して生成 |

### プロンプト生成まわり

| 画面のメッセージ | 意味 | やること |
|---|---|---|
| `ERROR が残っています。内容を確認してください` | 3回の自動修復でも機械検査に通らなかった | 検査結果の行（D番号）を読む。手で直して「再検査」するか、「やり直す（seed+1）」で書き直させる |
| `場所と動きのどちらかは書いてください` | 推奨モードで両方が空欄 | どちらかを書く |
| モデル一覧の「未検証」 | そのモデルでの合格率を実測していない | 使ってもよいが、プロンプトの出来を必ず読む |
| `☁ クラウド LLM を使います`（確認ダイアログ） | クラウド切替中は生成のたびに料金がかかる（1回 約8〜9k トークン） | 了解して進めるか、「モデル」からローカルに戻す |
| LM Studio の既定設定について警告と「既定設定を直す」ボタン | LM Studio 側に残った既定コンテキスト長がアプリの指定より優先され、生成が数倍遅くなる状態 | ボタンを押す（バックアップを取ってから書き換えます）。押すまで書き換えは起きません |

### 切り抜きまわり

| 画面のメッセージ | 意味 | やること |
|---|---|---|
| `threshold を下げてください`（検出ゼロ） | threshold が高すぎて1人も検出されなかった | 「threshold を振ってみる」で人数の出る値を探す |
| `:1 は本体のバグで使えない` | 検出テキストの個数指定 `:1` は ComfyUI 本体が受け付けない | `:2` 以上にして、検出後に1人だけ選ぶ |
| 保存時の `検査に ERROR があります` | 背景の単色性や占有率が基準を外れた | プレビューを目で見て判断。小さすぎるなら「余白を詰める」 |

### 結果カードの注意書き（⚠）

| 注意書き | 意味 | やること |
|---|---|---|
| `bit_rate … は同解像度の正常域（…）より大きく低い。破損・ベタ塗り化の疑い` | 画が単調・破綻している可能性 | 動画を見て判断。破綻していれば seed を変えて再生成 |
| `音声トラックが無い` / `音量 … はほぼ無音` | 音が入らなかった | 音が要るなら再生成。効果音はブリーフの場所・動きから推測されるので、音の出る要素（雨・足音など）を書くのも手 |
| `フレーム数 N が指定 N と違う` | 指定した尺と違う長さになった | 尺を短くする（参照素材が多いほど破綻しやすい・実測） |

## 症状別の切り分け

### 指定した構図・カメラにならない

1. **開始の構図の下の判定**を見る。「成立しにくい」なら組み合わせ自体を変える（[04](04_ブリーフの書き方.md#開始の構図)）
2. **寄り・引きはカメラ（終端）で指定したか。** 開始の構図のサイズ指定より、終端で書く方が確実に通ります（実測 12/12）
3. カメラ欄が**空欄なら静止ショット**になります。動かしたいなら終端を書く
4. ダッチアングル・真俯瞰・望遠・広角を自由記述で書いていないか。**書いても効きません**（実測）
5. 右ペインの「ブリーフ（実際に LLM へ渡した文）」とプロンプト本文を読み、意図がそもそも英語本文に入っているかを確認

### 画面内の文字が違う字になる・出ない

- **別の字になった** — 稀少な漢字・異体字は「もっともらしい別の実在漢字」に置き換わります（実測）。入力時に「別の字になる恐れ」が出ていたはずです。常用の字に言い換えるのが確実
- **文字自体が出ない** — プロンプト本文に `"文字"` が引用符つきで入っているか確認（入っていなければ検査 D13 が ERROR を出します）。6文字以上は未検証域です
- 確認は**必ず人の目で**。機械検査は「本文に入っているか」までしか見ません

### キャラが参照と違う顔・服になる

1. 作品の設定でそのキャラに**説明**を書いたか（空だと見た目が伝わりません。[05](05_参照素材と切り抜き.md)）
2. 選んだ参照画像がそのキャラのエントリに紐づいているか（紐づいていない画像は「説明なし」として渡ります）
3. 参照画像が多すぎないか。他キャラの画像が混ざっていないか

### 背景に知らない部屋・元絵の背景が出る

- 生画像（背景つき）を参照に使っていないか — **本番では背景が漏れます**。切り抜きを通す
- 場所と時間の欄に**素材名入りの具体物**を書いたか — 雰囲気の形容だけでは参照画像の背景を押し返せません（実測 R9）

### 動きがおかしい・動かない

- 「動き」欄を**段階に区切って**書いたか。欄の下の段階表示が意図どおりに割れているか
- 最後に止まる状態まで書いたか
- 参照動画に期待しすぎていないか — **動きはテキストが支配的**です（実測 R5）

### 生成が数分〜10分近く固まる

進捗の `step 1` で長く止まることがあります。画面にも「⚠ step 1 に N 秒かかっています」という注意書きが出ます。

- **モデルの読み込みに時間がかかることがあります**（実測で6秒〜8分の幅）。**原因は分かっていません** — 空いている VRAM の量では説明がつかず（同じ空き容量から10秒のことも200秒超のこともある実測あり）、参照素材の有無やプロンプトの内容とも対応しません
- **そのまま待ってください。** 同じ設定で連続して生成しているとき（モデルが載ったまま）は速く返ります
- **ごくまれに、完了も中止もできなくなることがあります**（`/interrupt` が効かない）。そのときだけ ComfyUI を再起動してください
- **`--reserve-vram 3` は対処になりません。** 以前は推奨として案内していましたが、2026-08-25 に実測して撤回しました。付けて起動していても遅い本・完了も中止もできない本の両方が発生しています

### プロンプト生成が急に遅い（15秒 → 数分）

ComfyUI が VRAM を抱えたまま LLM を載せると、モデルの一部が CPU に載って数倍遅くなります（実測 45秒 → 218秒。見た目では分かりません）。アプリは載せ直しが要るときだけ ComfyUI を先に空けてから LLM を載せ、載りきったかを検算します — **自動で直らないときは、一度「モデル」→「全部降ろす」してからロードし直してください。**

### 中止が効かない・固まって見える

VRAM が逼迫していると ComfyUI の HTTP 応答自体が遅くなり、中止要求への反応に数十秒〜数分かかります（実測で応答に41秒）。**押したら待つ。** 連打や再起動はしない（生成中にサーバーを再起動するとジョブの追跡が切れます）。

### 生成のたびに同じ動画が返ってくる

同じ seed・同じプロンプトの再投入は ComfyUI がキャッシュを返すだけです（アプリが検出してログに出します）。**「seed+1 で再生成」**を使うか seed を変えてください。

### どうにも切り分けられないとき

- サーバーを起動した端末のログと、`jobs/<job id>/job.json` の `log` に詳細が残っています
- 環境の前提が崩れていないかは「設定」→「再チェック」が早い
- 既知の制限に当たっていないか [08. 付録](08_付録.md#できないこと未検証の一覧) を確認
