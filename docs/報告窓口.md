# 報告窓口 — 絵巻H3 で作られた出力について

**絵巻H3 を使って作られた動画が、誰かの権利を侵害している、または不適切な用途に使われている——そう気づいた方のための窓口です。**

**あなたが絵巻H3 の利用者である必要はありません。** 通りすがりに見つけた方からの報告も受け付けます。

## 何を報告していただきたいか

- **第三者の権利の侵害** — 著作権、商標、肖像権・パブリシティ権、その他の権利
- **MiniMax H3 の Acceptable Use Policy（利用規約・ライセンスの Exhibit A）が禁じている用途**での使用
- **法令に違反する用途**での使用
- **未成年者に関わる有害な内容**

**確信がなくても構いません。**「これは大丈夫なのか」という段階の問い合わせも歓迎します。判断を求められて困ることより、報告されないことのほうが問題です。

**⚠ 絵巻H3 そのものの不具合・要望は、この窓口ではなく通常の Issue へお願いします。**

## どこへ報告するか

**内容によって2つの経路があります。どちらを選んでいただいても構いません。**

### 1. 公開されてよい報告 → **Issues**

リポジトリの **Issues** に投稿してください。やりとりは公開されます。

### 2. 公開したくない報告 → **非公開の報告フォーム**

リポジトリの **Security** タブから、非公開で報告できます。**投稿者と私たちだけが読めます。**

> **⚠ ボタンの表記は「Report a vulnerability（脆弱性を報告）」です。**
> これは GitHub 側の表記で変更できません。**権利侵害やその他の報告にも、そのままお使いいただけます。**
> 「脆弱性ではないから」と遠慮しないでください。

**当事者ご本人か、代理の方か、第三者かは問いません。** お名前を明かさずに報告していただいても構いません。ただし**連絡先がないと、確認のための質問ができません。**

> **⚠ どちらの経路にも、GitHub のアカウントが必要です。**
>
> Issues も非公開の報告フォームも、GitHub の機能を使っているためです。**アカウントは無料で作成できます**（[github.com](https://github.com)）。
>
> **現時点で、アカウントなしで報告できる経路を、私たちは用意できていません。** これは私たちの側の制約です。**とくに、権利を侵害された方ご自身が開発者ではない場合に、この壁がいちばん高くなることは分かっています。**

### 報告に含めていただけると助かるもの

- **問題の対象がどこにあるか**（URL、投稿先、ファイル名など）
- **何が問題だと考えるか**（どの権利か、どの規定に触れると思うか）
- **あなたと対象の関係**（権利者ご本人／代理／第三者）— 任意です
- **返信先** — 任意ですが、あると確認が進みます

## 報告のあとに何が起きるか

1. **数日以内に、受け取ったことをお返事します。**
   *（見落としを防ぐための一次返答です。調査の結論ではありません。）*
2. **内容を確認します。** 追加の情報をお尋ねすることがあります。
3. **私たちの手が届く範囲で対応します。** 何をしたか、または**なぜできなかったか**をお伝えします。

**⚠ 具体的な時間の約束はしていません。** 守れない数字を書くほうが不誠実だと考えているためです。**返事がない場合は、遠慮なく催促してください。**

## 私たちにできること・できないこと

**ここが、この窓口でいちばん大事な部分です。**

| 対象 | できること |
|---|---|
| **私たち自身が公開した動画**（note・YouTube・pixiv・X など） | **削除できます** |
| **このリポジトリの中身** | **変更・削除できます** |
| **アプリの配布** | 止められます。**ただし MIT ライセンスで既に配布されたものは、私たちの手では戻せません** |
| **他の方の PC の中で生成されたもの** | **手が届きません** |
| **GitHub のアカウントをお持ちでない方からの報告** | **受け取る経路が用意できていません**（上記のとおり、どちらの経路にもアカウントが要ります） |

**絵巻H3 は、利用者ご自身の PC の中だけで動きます。** 私たちのサーバーを経由しません。**そのため、誰が何を生成したかを私たちは知りませんし、それを止める技術的な手段も持っていません。**

**これは免責の主張ではなく、境界の説明です。** 私たちに届かない範囲の報告をいただいた場合は、**そのことをお伝えし、可能であれば他にどこへ報告できるかをお示しします**（プラットフォームの通報窓口、MiniMax の連絡先など）。

## この窓口を設けている理由

MiniMax H3 の Community License の **V.5** は、H3 で出力を生成できる製品やサービスを第三者に提供する側に対して、**安全策を講じ、違反を報告できる窓口を維持し、報告を受けたら調査して停止・緩和すること**を求めています。

**この条項が、絵巻H3 のようなローカルで動くツールにどこまで掛かるのかについては、書かれているものが一致していません。** 詳しくは [ライセンスについて](./ライセンスについて.md) をご覧ください。

**判断する材料が揃っていないので、私たちは判断していません。**

**そのうえで、いちばん広く読むほうを選びました。**「掛かるかもしれない」ではなく、**「掛かる前提で動く」。**この窓口は、その結果です。

**⚠ ただし、できたのはそこまでです。**条文は**技術的な安全策**も求めていますが、**絵巻H3 には入れていません。**
ローカルで動くオープンソースなので、**入れても利用者の側で外せます。**「フィルタがあります」と言えるものを作って、**外されたときにその主張が嘘になる**より、**無いと書くほうを選びました。**
**——上の「私たちにできること・できないこと」と、地続きの話です。**

**⚠ これをもって「V.5 を満たしている」と主張するものではありません。** それは私たちが自分で判定できることではありません。**私たちがしていることを書いているだけです。**
