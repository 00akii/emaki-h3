ブリーフ 日本語でよい。空欄は既定値

「展開」を押すと推奨モードの欄に開きます。どう解釈したかを確認してから生成できます（展開されるのは場所・動き・カメラ・セリフの4つ。開始の構図と画面内の文字は必要なら手で足す）。
どこで・いつ・何でできているかを書く。素材名（コンクリート／鉄／硝子／木）を1つ入れると画が締まる。 夕立のあとの夕方、学校の屋上。濡れたコンクリート 夜の自室。木の机と紙のノート、硝子のコップ 参照画像の背景が漏れるのを、新しい場所の具体物で押し返す（実測 R9）。幻想的な雰囲気の場所 は画に落ちない。
順番どおりに区切って書く。3〜5段階が目安。最後に止まる状態まで書く。 机に座っている 顔を上げる 立ち上がる 鞄を肩にかける 区切りは打ちやすいもので構いません — スペース・読点「、」・ハイフン「-」・改行・矢印「→」のどれでも同じに扱います（上に解釈結果が出ます）。
動きの質は参照動画ではなくこの文章で決まる（実測 R5）。自然に動く いい感じに は何も渡らない。
1フレーム目の構図。高さ（目線／ハイ／ロー）と視点（正面／真横／背面）は確実に効く。寄り（胸から上より近い）を選んでカメラが引かない場合は、本文を画角内の要素に絞る修正が自動で入る（実測: 絞らないと×9、絞ると×0）。寄りから引く組み合わせは成立しにくいので警告が出る。ダッチアングル・真俯瞰・望遠 は効かないので選択肢にない。
終端の構図を書くと効きます（実測 12/12）。空欄だと静止ショットになります。寄り／引きは開始よりこちらで指定する方が通る。到達する画角は目安で保証ではない。
看板・札・画面に出す文字。カギカッコの中が一字一句そのまま出ます。前に「看板に」「ネオンで」など載せる物を書けます（無ければ LLM が画角内に看板か画面を置く）。常用漢字・かな・英数は正確に出る（実測 9/9）。稀少な漢字・旧字体 は別の実在漢字に静かに置き換わることがある（鵺鰰→別字、髙﨑→高崎）ので、入力時に警告が出ます。カメラが動いても崩れない。寄りの構図を選んでも、この欄は「画角には入らない」扱いにならない。
話者（性別・年齢・声質）「本文」の形。カギカッコの中は一字一句そのまま入ります。8秒なら日本語30文字以内が目安。
MODE / DURATION / RATIO / STYLE / REFS / SHOT / FRAMING / CAMERA / DIALOGUE / SOUND / MUSIC をそのまま書きます。

設定

赤い項目は config.json を直してください。パスはすべてここに外出ししてあり、コードには書いていません。
N ComfyUI のノード
「本体」は ComfyUI 0.33 以降に最初から入っています。それ以外は ComfyUI Manager などで導入してください。必須が欠けていると生成できません。
W 重みファイル ワークフロー JSON から読んだ名前で照合
名前が違うと出た場合は、ComfyUI で H3 のワークフローを開いて保存し直すか、config.json の workflow_json をその環境のものに向けてください。
E Eagle に送る
送るのは音付きの1本だけです。ComfyUI の SendToEagleVideo は無音版と音付き版の2本を送ってしまうため使っていません。注釈にはプロンプト本文・ブリーフ・計測値（フレーム数／実尺／bit_rate／音量／フレーム間差分）が入り、タグは作品名・ショットID・本番/プレビュー・比率が付きます。
